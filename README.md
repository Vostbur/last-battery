# Последняя батарея

**Последняя батарея** — браузерная point & click игра на чистом HTML, CSS и JavaScript.

## Запуск локально

Откройте `index.html` в браузере.

Для полноценной работы в некоторых браузерах удобнее запускать проект через простой локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Структура проекта

- `index.html` — основной HTML игры.
- `styles.css` — оформление интерфейса и сцены.
- `app.js` — игровая логика, состояния локаций, предметов и переходов.
- `assets/locations/` — изображения локаций.
- `assets/sprites/` — персонажи, двери и элементы переходов.
- `assets/items/` — предметы.
- `assets/maps/` — карта и мини-карта.

## Игровая механика

Игра построена вокруг исследования локаций, взаимодействия с предметами и персонажами и последовательного выполнения задач.

Основные действия выполняются кликом по объектам сцены. Переходы между локациями привязаны к соответствующим дверям и проходам.

## GitHub Pages

Проект публикуется через **GitHub Pages** с использованием GitHub Actions.

**Играть онлайн:** https://vostbur.github.io/last-battery/

Workflow находится в `.github/workflows/pages.yml`. Каждый push в ветку `main` автоматически публикует актуальную версию игры.
